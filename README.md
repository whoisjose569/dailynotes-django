# 📝 DailyNotes

Projeto de estudo com Django para gerenciar entradas de diário, com suporte a múltiplas pessoas relacionadas e tags por texto.

## 🚀 Funcionalidades

- Criação de entradas de diário com título e corpo  
- Associação de múltiplas pessoas por entrada  
- Adição de tags customizadas em cada entrada  
- Listagem filtrada por data

## ✍️ Objetivo do Projeto

Esse projeto foi criado com o propósito de praticar:

- Manipulação de formulários em Django (GET e POST)  
- Relacionamentos entre modelos (`ManyToMany`)  
- Boas práticas de templates e estrutura de views  
- HTML com classes utilitárias do Tailwind  

## 📌 Observações

Este projeto não inclui autenticação nem restrição de acesso, pois o foco está no uso de formulários, modelos e relacionamento de dados com Django.
